# NITI — แผนปฏิบัติการฉุกเฉินหมู่บ้านจัดสรร

โครงการเอกสารตัวอย่างสำหรับนิติบุคคลหมู่บ้านจัดสรรและเจ้าหน้าที่รักษาความปลอดภัย (รปภ.) เริ่มต้นจากเหตุไฟไหม้บริเวณติดหมู่บ้านช่วงเช้ามืด และขยายครอบคลุมภัยที่พบบ่อย

## สถานะ
**เอกสารตัวอย่างเพื่อใช้ปรับแก้ ไม่ใช่แผนที่อนุมัติใช้แล้ว** ก่อนประกาศใช้ต้องสำรวจผังหมู่บ้านจริง กำหนดบ้านในโซน A/B/C จุดรวมพล ทางเข้ารถดับเพลิง ผู้รับผิดชอบ กำลัง รปภ. และโทรศัพท์ประจำพื้นที่ รวมถึงฝึกซ้อมร่วมกับสถานีดับเพลิงท้องถิ่น

**สำคัญด้านข้อมูลส่วนบุคคล:** ไม่ใส่รายชื่อ เบอร์โทร ข้อมูลสุขภาพ หรือสถานะอยู่อาศัยของลูกบ้านจริงใน repository สาธารณะนี้ ให้จัดเก็บบัญชีแจ้งเตือนตัวจริงไว้ในระบบที่จำกัดสิทธิ์ของนิติบุคคล

## การนำไปใช้
1. นิติบุคคลและคณะกรรมการตรวจทาน/อนุมัติ
2. สำรวจพื้นที่และกรอกแบบฟอร์มผังบ้านโซนเสี่ยง
3. แจกบัตรสั่งการทุกกะ ติดเบอร์โทรประจำพื้นที่ และทดสอบการแจ้งเตือน
4. ซ้อมสถานการณ์ไฟไหม้ช่วงเช้ามืดและทบทวนผลการซ้อม
